# Java Day 46 - Online Shopping Cart System

## Description
An Online Shopping Cart System developed using Java. Users can browse products, add items to a cart, remove products, calculate discounts, and place orders.

## Features
- Display available products
- Add products to shopping cart
- Remove products from cart
- Calculate cart total
- Apply 10% discount on orders of Rs. 5000 or above
- Save order details in CSV

## Files
- `Main.java` - Main Java program
- `products.csv` - Product information
- `orders.csv` - Order history

## How to Run
Keep all three files in the same working directory.

Compile:

`javac Main.java`

Run:

`java Main`

## Concepts Used
- Object-Oriented Programming
- Classes and Objects
- ArrayList
- File Handling
- CSV Data Management
- Exception Handling
- Shopping Cart Calculations
